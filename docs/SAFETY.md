# Safety

Apex never automatically disables services, removes protected Windows components, removes Edge/WebView2, disables Defender, disables Windows Update, resets network adapters, or reboots. Optional current-user consumer app/Store removal is separately confirmed and has an explicit best-effort restore path; Store-dependent applications may stop working. Protected dependencies include Windows Update, Security, Installer, WinRE, Plug and Play, networking, Bluetooth, audio, USB, DirectX, .NET, Visual C++, WebView2, Microsoft/Xbox sign-in, Gaming Services, activation, Explorer, Task Manager, Device Manager, and Event Viewer.

Reversible current-user changes include visual effects, Game Mode/Game DVR, RAM Saver background-app policy, Explorer context-menu state, dark/light theme, transparency, and desktop wallpaper. The first apply snapshots prior state; restore uses that snapshot where supported. Power profiles are clones of Windows Balanced and remain installed after selecting the prior active plan again. Backups cover Apex files and known snapshots, not the complete Windows installation or arbitrary third-party settings.

Startup management is limited to selected current-user Run registry values. Apex saves the value name, command, registry view, and value kind before removal; restore does not overwrite a value recreated by another application and retains any conflicting backup for review. Actual installed power schemes can be selected by their enumerated GUID, and the previously active GUID is saved for restore. The Toolbox marks actions SAFE, ADVANCED, or EXPERIMENTAL; any experimental apply requires a confirmation, and no experimental actions are currently offered.

Power profiles clone Windows Balanced and make limited processor changes. Selected major repairs/removals can offer a restore point; if the user requests one and Windows fails to create it, the operation is aborted. Compatibility has not been proven for a build merely because Apex detects Windows 11/26H2. Restore points may be unavailable due to Windows policy.
