# Feature status

Implemented actions are listed in `config/toolbox.json` and launch separate PowerShell scripts. All category page structures are constructed at launch; category changes switch visibility rather than rebuild pages. Actions display SAFE, ADVANCED, or EXPERIMENTAL risk labels; experimental actions are rejected by project validation unless confirmation is required, and the UI enforces confirmation at apply time. No experimental action is currently exposed.

Power controls enumerate installed Windows plans dynamically, allow selecting an exact installed plan by its detected GUID, verify the active scheme, and restore the previously active plan. Optional Apex performance profiles clone detected Windows plans and apply only supported processor settings. Startup management inventories current-user Run registry values and offers confirmed disable with exact value/type backup and restore; it does not touch services, tasks, other users, or Startup-folder entries. RAM Saver has detectable OFF/BALANCED/AGGRESSIVE states backed by a per-user policy, not memory-cache clearing. Driver and network diagnostics, Windows Update driver search, component inventory, WebView2/Edge distinction, and system reports are implemented. Gaming Mode saves current-user values, disables Game DVR capture, and links to Game Mode, Game Bar, and per-app graphics settings. Repair Center covers selected DISM/SFC/update-cache/Installer operations plus diagnostics for Game Services, Xbox sign-in, Explorer, and WinRE. No script automatically reboots Windows.

Optional current-user consumer-app and Store removal is allowlisted and confirmed; Store restore depends on the original manifest remaining available. Edge is not removed; Chrome and NanaZip actions use Windows settings rather than editing protected default-app hashes. First-run setup preselects Chrome but does not install it until the user applies that selection; Keep existing, Firefox, and Brave remain available. Wallpaper, dark/light theme, transparency, startup controls, search/indexing shortcuts, and GPU preference settings are available. Optional Windows feature/capability management, scheduled-task controls, broad service/privacy tuning, and global CPU/filesystem/boot tweaks remain unimplemented or intentionally excluded. Unsupported/empty categories show Coming Soon rather than a blank page. Windows 11 26H2 and physical hardware require testing on corresponding Windows installations.

Current Linux checks establish static validity and compilation only. No Windows runtime, AME import, `.apbx` archive, or live system action is verified by those checks.
